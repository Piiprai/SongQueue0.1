      🎧 ปุ่มฟังเพลง (YouTube)

      เปิดในแท็บ YouTube เดียวกันทุกครั้ง · คลิกขวาที่ปุ่ม (มือถือ: กดค้าง) = คัดลอกลิงก์เพลง
      YouTube API Key (ไม่บังคับ)
      สร้างฟรีที่ Google Cloud → เปิดใช้ YouTube Data API v3 → Credentials → Create API key

      🛡️ แอดมิน

      แอดมินพิมพ์คำสั่งในแชทไลฟ์เพื่อจัดคิวได้
      คำสั่งที่ใช้ได้
      !ถัดไป / !next — เล่นเพลงถัดไป
      !จบ / !done — จบเพลงที่เล่นอยู่
      !ลบ 3 / !del 3 — ลบคิวลำดับที่ 3
      !ขึ้น 3 / !top 3 — ดันลำดับที่ 3 ขึ้นบนสุด
      !เล่น 3 / !play 3 — เล่นลำดับที่ 3 เลย
      !อนุมัติ 3 / !ok 3 — อนุมัติเพลงที่รออยู่
      !เพิ่ม ชื่อเพลง / !add — เพิ่มเพลง (ไม่นับโควตา)
      !ล้างคิว / !clear — ล้างคิวทั้งหมด
      เจ้าของไลฟ์ใช้คำสั่งได้เสมอ
