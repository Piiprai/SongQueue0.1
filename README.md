# 🎵 จัดคิวเพลง TikTok Live

เว็บแอปช่วย VJ จัดคิวเพลงจากแชท TikTok Live **ไม่ต้องติดตั้งอะไร เปิดในเบราว์เซอร์ได้เลย**
คนดูพิมพ์ `ขอเพลง ชื่อเพลง` ในแชท → เพลงเข้าคิวอัตโนมัติ

## ความสามารถ
- 💬 จับข้อความขอเพลงจากแชทไลฟ์ (ตั้งคำได้เอง เช่น `ขอเพลง`, `!song`)
- ✂️ ตัดคำลงท้ายและอีโมจิออกให้ เช่น `ขอเพลง ลมหนาว ค่ะ 🙏` → **ลมหนาว**
- 📋 จัดคิว: เล่นเลย / เลื่อนขึ้น-ลง / แก้ชื่อ / ลบ / เพิ่มเพลงเอง
- 🚫 จำกัดจำนวนเพลงต่อคน, กันเพลงซ้ำ, โหมดต้องอนุมัติก่อน
- 📺 หน้าต่าง Overlay สำหรับ OBS / TikTok LIVE Studio
- 🎧 ปุ่มฟังเพลง **ต้นฉบับ** และ **คาราโอเกะ** (เปิดใน YouTube)
- 🛡️ แอดมินจัดคิวผ่านคำสั่งในแชทได้
- 💾 คิวบันทึกในเบราว์เซอร์ ปิดแล้วเปิดใหม่ยังอยู่

## เปิดใช้บน GitHub Pages
1. ไปที่ **Settings → Pages** ของ repo นี้
2. หัวข้อ **Branch** เลือก `main` และ `/ (root)` แล้วกด **Save**
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ตั้งค่าครั้งแรก (API Key ฟรี)
แอปดึงแชทไลฟ์ผ่าน [Euler Stream](https://www.eulerstream.com)
1. สมัครที่ eulerstream.com → Dashboard → **API Keys** → สร้าง Key
2. นำ Key มาวางในช่อง 🔑 ของแอป แล้วกด **บันทึก**

Key จะเก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น ไม่ได้อยู่ในโค้ดบน GitHub

## วิธีใช้ตอนไลฟ์
1. เริ่มไลฟ์ใน TikTok
2. เปิดลิงก์แอป ใส่ `@ชื่อผู้ใช้` แล้วกด **เชื่อมต่อ** (ไฟเขียว = พร้อม)
3. ร้องหรือเปิดเพลงจบแล้ว กด **▶ เพลงถัดไป**
4. เปิดแท็บแอปค้างไว้ตลอดการไลฟ์

## 🎧 ปุ่มฟังเพลง
ทุกเพลงในคิวมีปุ่ม **▶ ต้นฉบับ** และ **🎤 คาราโอเกะ** กดแล้วจะเปิดผลค้นหาเพลงนั้นใน YouTube
- เปิดในแท็บ YouTube เดียวกันทุกครั้ง
- ตั้งคำค้นเพิ่มได้ เช่น ต้นฉบับ = `official`, คาราโอเกะ = `คาราโอเกะ karaoke`
- ตั้งให้กด **เพลงถัดไป** แล้วเปิดเพลงให้อัตโนมัติได้
- ครั้งแรกถ้าเบราว์เซอร์ถามเรื่องป๊อปอัป ให้กด **อนุญาต**

## 🛡️ แอดมินช่วยจัดคิว
แอดมินพิมพ์คำสั่งในแชทไลฟ์เพื่อจัดคิวได้ ตั้งว่าใครเป็นแอดมินได้ที่กล่อง 🛡️ แอดมิน
(ใส่ชื่อผู้ใช้เอง หรือให้นับ Moderator ของไลฟ์อัตโนมัติ) ส่วนเจ้าของไลฟ์ใช้คำสั่งได้เสมอ

| คำสั่ง | ทำอะไร |
|---|---|
| `!ถัดไป` / `!next` | เล่นเพลงถัดไป |
| `!จบ` / `!done` | จบเพลงที่เล่นอยู่ |
| `!ลบ 3` / `!del 3` | ลบคิวลำดับที่ 3 |
| `!ขึ้น 3` / `!top 3` | ดันลำดับที่ 3 ขึ้นบนสุด |
| `!เล่น 3` / `!play 3` | เล่นลำดับที่ 3 เลย |
| `!อนุมัติ 3` / `!ok 3` | อนุมัติเพลงที่รออยู่ |
| `!เพิ่ม ชื่อเพลง` / `!add` | เพิ่มเพลง (ไม่นับโควตา) |
| `!ล้างคิว` / `!clear` | ล้างคิวทั้งหมด |

ถ้าคนดูทั่วไปพิมพ์คำสั่งเหล่านี้ แอปจะไม่ทำอะไร

## Overlay ขึ้นจอไลฟ์
1. กด **เปิดหน้าต่าง Overlay** (หน้าต่างพื้นสีเขียว)
2. ใน OBS / TikTok LIVE Studio เพิ่ม **Window Capture** แล้วเลือกหน้าต่าง "Overlay คิวเพลง"
3. ใส่ฟิลเตอร์ **Chroma Key** สีเขียว
4. ในหน้าต่าง Overlay กดปุ่ม `B` เพื่อสลับสีพื้นหลังได้

## เวอร์ชันรันบนเครื่อง
โฟลเดอร์ `local-version/` เป็นเวอร์ชัน Node.js ที่ไม่ต้องใช้ API Key และ Overlay ใช้เป็น Browser Source ได้โดยตรง
รันโดยดับเบิลคลิก `start.bat` (ต้องติดตั้ง [Node.js](https://nodejs.org) ก่อน)
